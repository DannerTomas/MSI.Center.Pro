# MSI Center Pro

更好的 MSI 笔记本控制中心，打开速度不知比官方版快到哪里去了。

## 功能

- 性能模式切换（狂暴 / 均衡 / 静音），实时写入 EC
- 酷寒散热开关
- 系统监控：CPU / GPU 使用率、频率、温度、风扇转速
- 磁盘清理、内存释放
- 浅色 / 深色主题

## 运行要求

- Windows 10 / 11 (x64)
- MSI 笔记本（已验证：Alpha 17 C7VF / MS-17KK）
- 管理员权限

## 构建

```
dotnet build MSICenterPro/MSICenterPro.csproj -c Release
```

## 说明

- 非官方构建，与微星官方无关
